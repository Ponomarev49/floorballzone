# Floorball Zone v0.2

Стартовый многостраничный прототип интернет-магазина Floorball Zone на React + Vite.

## Запуск

```bash
npm install
npm run dev
```

## Страницы

- `/` — главная
- `/catalog` — весь каталог
- `/category/клюшки` и остальные категории
- `/product/1` — карточка товара
- `/brands` — бренды
- `/brand/zone` — товары бренда
- `/sale` — Sale
- `/help` — подбор экипировки
- `/teams` — для команд
- `/blog` — статьи
- `/about` — о магазине
- `/contacts` — контакты
- `/order` — временный заказ

## Важно

Ассортимент и фотографии сейчас демонстрационные. Названия брендов основаны на предыдущем обсуждении; перед публикацией их нужно сверить с реальным каталогом Floorball Zone VK.

Для продакшена следующий этап — заменить mock data на API/JSON/CRM, подключить реальные фотографии и сделать нормальную корзину, доставку и оплату.
